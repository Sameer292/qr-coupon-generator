Manage cash-prize promotional coupons, validate QR token scans, collect claimant data, and execute manual end-of-day payouts.

== Description ==

FM Cash Claims is a standalone WordPress plugin designed for high-security promotional cash coupon campaigns. Coupled with the client-side QR Coupon Generator, it securely manages the complete lifecycle of cash-prize coupons from manifest import to claim submission and manual daily payouts.

### Key Capabilities

* **Import Manifest Batches**: Securely imports `manifest.csv` files generated by the client-side generator. Validates column headers, token entropy, duplicate entries, and batch parameters before committing.
* **Server-Side Token Masking**: Import previews display masked tokens (first 6 and last 4 characters) to prevent shoulder-surfing and accidental disclosure in admin views.
* **First-Come, First-Claimed Concurrency**: Atomic MySQL database locking (`FOR UPDATE`) ensures each prize token can only be claimed once, eliminating double-claim race conditions.
* **Secret Token Scans**: QR codes carry only a 32-character cryptographically secure token. Prize amounts are revealed only after a valid scan.
* **Privacy-First Public Status**: Claim success responses use single-use transient keys. Subsequent public status queries display only the coupon code and claim status without exposing claimant names, phone numbers, or claim references.
* **Manual End-of-Day Payouts**: Filter, search, and review pending claims, mark individual claims as paid with payment notes, or execute bulk payout updates.
* **Reconciliation Export**: Export filtered claim records to CSV with UTF-8 BOM encoding for seamless spreadsheet reporting and accounting sign-off.
* **Auditing & Logging**: Every scan attempt, claim submission, rejection, reopen, and payout is logged with IP address and timestamp.
* **Clean Uninstall**: Comprehensive uninstall script cleans up custom tables (`fm_cash_*`) and transients upon plugin deletion.

== Installation ==

1. Upload the `fm-cash-claims` directory to your WordPress `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to **Cash Claims &rarr; Settings** to set your claim window (in days), max claims per phone number, currency code, and support contact details.
4. Navigate to **Cash Claims &rarr; Import** to upload your batch `manifest.csv` *prior* to distributing physical coupons.
5. Verify rewrite rules by visiting **Settings &rarr; Permalinks** and clicking "Save Changes" if using pretty permalinks. The public claim URL is accessible at `/claim/?t=<token>` (fallback query parameter `?fm_cash_claim=1&t=<token>` is also supported).

== Frequently Asked Questions ==

= Why must manifest.csv be imported before coupon distribution? =
The manifest contains the secret 32-character tokens and prize allocations. If coupons are distributed before import, scanners will see an "Unrecognized coupon" error and will be unable to claim their prize.

= What fields are collected on the claim form? =
Claimants provide their Full Name and Phone Number (mandatory). A 9-digit PAN is optional. Claimants must also agree to the campaign terms.

= How does the one-time success key work? =
Immediately after successful claim submission, the claimant is redirected with a one-time transient key displaying their claim reference and submitted details. Once viewed, this transient is deleted so reload or shared URLs cannot expose personal data.

= Can a batch be deleted after distribution? =
A batch can only be deleted if no coupons from that batch have been claimed or modified. Once claims exist, batch deletion is blocked to preserve financial and audit integrity.

= How are duplicate claims prevented? =
Coupons are tracked in MySQL with unique constraints and checked in atomic transactions with `FOR UPDATE` row locks. The first valid submission transitions the coupon from `issued` to `claimed`.
